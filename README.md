# 우리 동네 접근성 모험 (v0.2 · 캠페인 참여 기능 포함)

동네를 여행하며 막힌 상황을 **접근성 아이템**으로 풀고, 그때마다 **동네가 실제로 바뀌는** 1~2분짜리 웹 체험 게임입니다.
게임이 끝나면 참여자가 **실제로 이용하기 편했던 우리 동네 장소를 추천**하고, 원하는 사람만 경품 추첨에 응모하는 온라인 캠페인으로 이어집니다.
마을축제·캠페인 부스·학교 교육에서 휴대폰이나 태블릿으로 바로 실행할 수 있어요.

- 점수, 목숨, 제한시간, 실패 화면이 없습니다. 오답을 골라도 힌트를 보고 다시 고르면 됩니다.
- 주인공은 특정 장애 유형이 아닌 '동네 탐험가'입니다. 주민들은 각자의 방법으로 동네를 이용하는 이웃으로 자연스럽게 등장합니다.
- 질문은 "누구를 도와줄까?"가 아니라 "어떻게 하면 더 많은 사람이 이용할 수 있을까?"를 묻습니다.

## 1. 바로 실행하기

| 방법 | 설명 |
|---|---|
| 내 컴퓨터에서 | 폴더를 풀고 `index.html`을 더블클릭합니다. |
| 버전 바꾸기 | 주소 끝에 `#film`(배리어프리 영화), `#school`(학교 교육)을 붙입니다. 아무것도 없으면 마을축제 버전이에요. 참여자는 버전을 바꿀 수 없고, 시연용으로 버튼이 필요하면 `js/data/settings.js`에서 `showVersionSwitch: true`로 바꾸세요. |
| 소리 | 첫 버튼을 누르면 효과음이 켜집니다. 오른쪽 위 스피커 버튼으로 끌 수 있어요. |
| 저장 | `campaign.js`에 저장 주소가 없으면 **미리보기 모드**로, 폼을 끝까지 해 볼 수 있지만 저장되지는 않아요. |

> 글꼴(Do Hyeon, Noto Sans KR, Silkscreen)은 Google Fonts에서 불러옵니다. 인터넷이 없어도 게임은 돌아가지만 기본 글꼴로 보입니다.

## 2. 게임 흐름

```
START → STAGE 1~3 → FINAL(도착) → 달라진 동네 다시 보기 → MISSION COMPLETE
      (이동 중 ⭐ 모으기 → 상황 발견 → '?' 상자 → 4지선다 → 환경 변화 → 아이템 획득)
  → [우리 동네 접근성 알려주기] 추천 장소 남기기 → (선택) 경품 추첨 응모 → 완료 화면
```

- 추천할 곳이 떠오르지 않으면 **[추천할 곳이 아직 없어요]**로 바로 완료 화면에 갈 수 있어요.
- 경품 추첨 체크박스를 누르지 않으면 이름·연락처를 묻지 않습니다.
- **별**: 걷기만 해도 자동으로 모여요. 이동 중에 화면을 톡 누르거나(키보드: 스페이스바·↑) 점프해서 잡으면 반짝 보너스! 모은 별은 마지막 축제 광장의 전구로 켜집니다(점수·개수 표시 없음).

| 단계 | 마을축제 버전(기본) | 화면에서 바뀌는 것 |
|---|---|---|
| STAGE 1 | 가게에 들어가고 싶어요! | 가게 입구 옆에 손잡이 달린 **경사로**가 생기고, 탐험가가 경사로로 들어갑니다. |
| STAGE 2 | 중요한 안내를 놓쳤어요! | "띵동~" 방송 뒤 **전광판**이 켜지고 "다음 버스는 3분 뒤 도착합니다."가 흐릅니다. |
| STAGE 3 | 메뉴를 어떻게 확인하지? | **점자 메뉴 · 메뉴 듣기 · 큰 글씨 메뉴 · 직원 안내**가 차례로 나타납니다. |
| FINAL | 우리 동네가 달라졌어요! | 처음 지나온 동네를 다시 보여주고, 주민들이 경사로·전광판·메뉴 입간판을 이용합니다. |

## 4. 문구·선택지 고치기 (코딩 몰라도 OK)

`js/data/theme-village.js`를 메모장이나 VS Code로 열고, **따옴표 안의 글자만** 바꾸고 저장하면 됩니다.

```js
{
  scene: 'entrance',                        // 어떤 장면 틀을 쓸지 (아래 표 참고)
  title: '가게에 들어가고 싶어요!',          // 스테이지 제목
  place: { sign: '동네상회', style: 'shop' },// 간판 글자, 건물 모양
  lead: '어? 입구에 계단이 있네요.',          // 말풍선 첫 줄
  question: '더 많은 사람이 편하게 드나들려면\n무엇이 있으면 좋을까요?',  // \n = 줄바꿈
  wrong: '앗! 이것으로는 길을 지나가기 어렵겠어요.\n다른 아이템을 골라볼까요?',
  choices: [
    { label: '경사로', icon: 'ramp', correct: true },   // 정답에만 correct: true
    { label: '더 높은 계단', icon: 'stairs', hint: '계단이 높아지면 오르내리기가 더 힘들어져요.' },
    ...
  ],
  item: { name: '경사로', icon: 'ramp', desc: '…', note: '…' }
}
```

- 선택지 순서는 게임할 때마다 자동으로 섞입니다. 데이터에서는 정답을 어디에 두어도 됩니다.
- `hint`는 오답을 골랐을 때 보이는 짧은 설명입니다.
- `item.short`를 넣으면 엔딩·HUD에 짧은 이름으로 나옵니다. (예: '다양한 방법으로 제공하는 정보' → '다양한 정보')
- `a11y.before / after`는 화면낭독기 사용자에게 읽어 주는 장면 설명입니다.

**쓸 수 있는 장면 틀**

| scene | variant / style | 쓰임 |
|---|---|---|
| `entrance` | style: `shop` · `theater` · `school` | 입구 계단 → 경사로 |
| `board` | variant: `busstop` · `screen` | 소리만 나오던 안내 → 전광판/자막 |
| `infopoint` | variant: `cafe` · `cinema` · `classroom` | 실내 안내판 → `methods`에 적은 방법들이 차례로 나타남 |

**infopoint의 methods 아이콘**: `braille`(점자) · `speaker`(음성) · `bigtext`(큰 글씨) · `staff`(사람 안내) · `headphones`(화면해설) · `cards`(그림카드) · `cc`(자막)

**아이콘 이름**: `ramp` `stairs` `door` `slip` `text` `loud` `up` `dark` `small` `fast` `multi` `braille` `bigtext` `speaker` `staff` `headphones` `cc` `cards` `home` `shop` `bus` `cup` `flag` `film` `school` `screen` `star`

## 5. 새 캠페인 버전 만들기

1. `js/data/theme-village.js`를 복사해서 `theme-새이름.js`로 저장합니다.
2. 맨 위 `id`를 겹치지 않는 영어 이름으로(예: `'library'`), `label`을 버튼에 보일 이름으로 바꿉니다.
3. 문구·선택지·아이템·`route`(경로 아이콘)·`world`(이웃 가게 이름, 도착지 이름)를 고칩니다.
4. `index.html`의 `<!-- 2) 스테이지 데이터 -->` 아래에 한 줄을 추가합니다.
   ```html
   <script src="js/data/theme-library.js"></script>
   ```
5. 주소 끝에 `#library`를 붙이면 새 버전으로 시작합니다. **가장 먼저 등록된 테마가 기본값**이에요.

> 스테이지 수는 3개가 기본이지만, `stages`에 넣은 수만큼 동네가 길어지고 HUD 동그라미도 늘어납니다.
> 완전히 새로운 장면(예: 엘리베이터, 키오스크)이 필요하면 `js/scenes/`에 파일을 추가하고 `AAG.registerScene('이름', {...})`으로 등록합니다. 기존 `entrance.js`가 가장 짧은 예시입니다.

## 6. Google Sheets 연결하기 (약 10분)

### 준비
1. Google 드라이브에서 **새 스프레드시트**를 만듭니다. (예: `2026 우리동네 접근성 캠페인 응답`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 지우고 `google-apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
4. 위쪽 함수 목록에서 **setup**을 고르고 ▶ **실행** → 권한 허용.
   - '추천장소', '추첨응모', '집계' 시트가 자동으로 생겨요.
5. (선택) **testInsert**를 실행하면 '추천장소'에 테스트 한 줄이 들어갑니다. 확인 뒤 지워 주세요.

### 웹 앱으로 배포
6. 오른쪽 위 **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**
   - 실행 사용자: **나** / 액세스 권한: **모든 사용자**
7. 나온 **웹 앱 URL**(…/exec로 끝남)을 복사합니다.
8. 게임 폴더의 `js/data/campaign.js`에서 `endpoint: ''` 따옴표 안에 붙여 넣고 저장합니다.
   ```js
   endpoint: 'https://script.google.com/macros/s/……/exec',
   ```
9. 다시 배포(GitHub Pages/Netlify)하면 끝! 이제 미리보기 모드 안내가 사라지고 실제로 저장됩니다.

> Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

### 저장되는 모습

**추천장소** 시트 (개인정보 없음)

| 응답ID | 참여일시 | 캠페인명 | 버전 | 추천 장소명 | 지역·동네 | 선택한 접근성 요소 | 요소별 열(1/0) ×8 | 기타 의견 | 추첨 참여 | 장소키 | 검토 상태 | 검토 메모 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

- 요소마다 열이 따로 있어(선택=1) 세기 쉽습니다.
- **장소키**는 장소명+지역에서 띄어쓰기를 뺀 값이라 같은 곳을 여러 번 추천하면 모아서 셀 수 있어요.
- **검토 상태**는 처음에 '확인 전'으로 들어갑니다. 담당자가 확인한 뒤 '확인 완료/보류' 등으로 바꿔 쓰세요.

**추첨응모** 시트 (개인정보 — 담당자만)

| 응답ID | 참여일시 | 캠페인명 | 이름·닉네임 | 연락처 | 개인정보 동의 | 동의 문구 버전 | 당첨 | 안내 완료 |
|---|---|---|---|---|---|---|---|---|

- 응답ID로 추천장소 시트와 연결됩니다. 이름·연락처는 **이 시트에만** 저장돼요.
- 동의 체크를 한 사람만 기록됩니다.

**집계** 시트 (수식으로 자동 계산)
- 전체 참여자 수 · 추천된 장소 수(중복 제외) · 경품 추첨 참여자 수 · 캠페인 수
- 접근성 요소별 선택 수(많은 순) · 지역별 추천 수 · 여러 번 추천된 장소

### 개인정보 운영 체크리스트
- [ ] 스프레드시트 공유는 담당자만. '추첨응모' 시트는 링크 공유 금지.
- [ ] `campaign.js`의 개인정보 안내·동의 문구를 기관 개인정보 처리 기준에 맞게 확인(문구를 바꾸면 `consentVersion`도 변경).
- [ ] 만 14세 미만은 보호자 동의가 필요해요. 안내 문구가 들어가 있으니, 기관 기준에 맞게 조정해 주세요.
- [ ] 캠페인 종료 후 Apps Script에서 **deletePrizeData**를 실행하면 추첨응모 데이터가 지워집니다.
- 게임은 입력 내용을 기기(브라우저)에 따로 남기지 않아서, 부스 태블릿을 여러 사람이 써도 앞사람 정보가 남지 않습니다.
- 스팸 방지용 숨은 칸이 있고, 같은 응답이 두 번 들어와도 응답ID로 한 번만 저장됩니다.

### 폼 문구 바꾸기
`js/data/campaign.js`에서 제목, 선택지(`features`), 안내 문구, 경품 문구, 완료 화면 문구를 바꿀 수 있어요.
선택지를 추가·삭제할 때는 `Code.gs`의 `FEATURES`도 같은 `key`로 맞추고 **setup**을 새 시트에서 다시 실행하세요.
캠페인 참여 화면 없이 게임만 쓰려면 `enabled: false`로 바꾸면 됩니다(엔딩에 [다시 모험하기]가 나와요).

## 7. 인터넷에 올리기

### GitHub Pages
1. GitHub에서 새 저장소를 만듭니다. (예: `access-adventure`)
2. **Add file → Upload files**로 이 폴더 안의 파일을 **폴더 구조 그대로** 올립니다. (`index.html`이 저장소 맨 위에 있어야 해요.)
3. **Settings → Pages → Branch: main / (root) → Save**.
4. 1~2분 뒤 `https://아이디.github.io/access-adventure/` 주소로 열립니다.
   - 영화 버전: `…/access-adventure/#film`, 학교 버전: `…/#school`

### Netlify
1. https://app.netlify.com/drop 에 접속합니다.
2. 압축을 푼 **폴더 통째로** 끌어다 놓으면 바로 주소가 생깁니다.

### 현장 운영 팁
- 태블릿은 화면 자동 회전을 켜 두면 가로/세로 모두 맞춰집니다. 가로 모드는 오른쪽에 선택지가 나옵니다.
- QR코드로 주소를 안내하면 참여자 휴대폰에서도 바로 할 수 있어요.
- 소음이 큰 부스에서는 소리를 꺼도 게임 진행에 문제가 없습니다(모든 정보가 화면에 글자로 나옵니다).

## 8. 접근성 설계

- 모든 버튼은 실제 버튼이라 **터치 · 마우스 · 키보드(Tab/Enter)** 모두 됩니다. 질문 중에는 **숫자 1~4**로 바로 고를 수 있어요.
- 정답/오답을 색만으로 구분하지 않습니다: 오답은 점선 테두리 + "↻ 다시" 표시 + 힌트 문장, 정답은 굵은 테두리 + "✓ 찾았다!" 표시.
- HUD의 아이템은 빈 동그라미 ○ / 아이콘이 든 동그라미 ●로 모양이 달라집니다.
- 화면낭독기용 장면 설명과 진행 안내(aria-live)가 있습니다.
- 운영체제의 '동작 줄이기' 설정을 켜면 카메라 이동과 효과가 짧아집니다.
- 제한시간이 없고, 아이템 설명은 **[계속 모험하기]**를 누를 때까지 기다려 줍니다.
